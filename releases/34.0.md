# Kernel

- Partial support for GCC `__attribute__((mode(<MODE>)))`.
- Fix bug of `-unspecified-access` in local definitions.
- Preliminary support for Windows.
- Frama-C now requires at least OCaml 5.2.0.
- Many API changes, with ocamlmig support, for external plug-ins developers.

# E-ACSL

- Fix and optimize runtime verification of absence of undefined logical terms and predicates.
- New meta option `-e-acsl-O` that configures the level of optimization.

# Eva

- Improve specification and verification of memory accesses to absolute addresses with `-absolute-valid-range`.
- New option `-eva-auto-partition-path` using heuristics for state partitioning according to program paths.
- Reduce default verbosity of analyses with `-mthread`, configured by `-eva-verbose`.
- More user-friendly help messages with `-eva-help`.
